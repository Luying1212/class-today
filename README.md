# 今日课表

24级软件工程（专升本）4班 · 打开即看今天上什么、下一节、教室与老师。

## 本地预览

用浏览器直接打开 `index.html`，或：

```bash
npx --yes serve .
```

## 放到微信里

需要一个公网 HTTPS 链接。可用 GitHub Pages / Cloudflare Pages / Vercel 部署本目录后，把链接发到微信收藏或聊天记录。

## 配置

- `TERM.week1Start`：第 1 周周一（当前为 `2026-09-07`）
- `PERIODS_A` / `PERIODS_B`：教学楼与行政楼作息（第 3–4 节相差 20 分钟）
- `SCHEDULE`：课表数据（教室以「行」开头按行政楼作息）
